# Fluxos

## Solicitar cuidado
Lidianne → escolhe um pedido → pedido fica pendente → Vinícius visualiza → responde. Ver [[Pedidos]].

## Mood
Lidianne → seleciona como está → estado fica disponível para a outra perspectiva. Ver [[Mood]].

## Espaço pessoal
Lidianne → ativa “Um tempo só seu” → Vinícius recebe o contexto → Lidianne encerra quando quiser. Ver [[Espaço Pessoal]].

## Mural
Planejado: casal → deixa pequenos recados/desenhos → outra pessoa visualiza. Ver [[Mural]].
