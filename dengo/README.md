# Dengo — Obsidian

Base versionada de conhecimento do Dengo, com documentação de produto, UX, regras de negócio, planejamento e backlog.

Abra esta pasta como vault ou copie seu conteúdo para uma pasta `Dengo` no vault existente. Comece por [[00 - Home]].

## Status
- ⚪ Ideia
- 🟡 Planejamento
- 🔵 Em desenvolvimento
- 🟢 Implementado

## Responsabilidades
**`dengo/`:** documentação versionada de produto, UX, regras de negócio, planejamento, backlog e ideias. Pode ser consultada pelos agentes como contexto do produto e aberta como vault no Obsidian.
**`docs/decisions/`:** ADRs e decisões técnicas relevantes.
**`app/`:** implementação e testes.

As decisões necessárias para implementar uma etapa devem estar claras na documentação ou na especificação da etapa. Decisões técnicas relevantes continuam sendo registradas nos ADRs.
