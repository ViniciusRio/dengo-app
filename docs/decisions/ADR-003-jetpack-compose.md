# ADR-003 — Kotlin + Jetpack Compose + Material 3

## Status
Aceito.

## Decisão

O cliente Android será desenvolvido em Kotlin usando Jetpack Compose. Material 3 será usado como fundação de componentes, acessibilidade e theming, com customização pelo design system do projeto.

## Motivo

O produto depende de componentes visuais próprios, estados de UI e iteração rápida de design. Compose reduz o custo de prototipação e mantém a UI declarativa.
