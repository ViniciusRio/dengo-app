# ADR-005 — MVP fechado em Lidianne e Vinícius

## Status
Aceito para protótipo.

## Decisão

O MVP não terá cadastro público nem sistema genérico de múltiplos casais. A experiência será validada especificamente nas perspectivas de Lidianne e Vinícius usando dados fake/local.

## Consequência

Autenticação, pareamento e sincronização real serão discutidos somente após validar produto e UI localmente.
