# ADR-004 — Direção visual e personagens

## Status
Aceito.

## Decisão

A identidade inicial usa tema claro com base creme/off-white, Lidianne associada a rosa e Vinícius associado a azul. Os personagens são originais em linguagem chibi/pixel-art suave.

Lidianne: pele branca, cabelo longo castanho escuro, óculos claros e roupa casual suave.

Vinícius: pele morena clara, cabelo preto extremamente curto (máquina 0,5–1) e roupa casual simples.

A arte `docs/design/references/approved/01-approved-design-direction.png` é referência de direção, não especificação pixel-perfect.

## Consequências

- rosa/azul funcionam como acentos contextuais sobre uma base visual compartilhada;
- componentes continuam reutilizáveis entre as duas perspectivas;
- novos assets devem preservar identidade dos personagens;
- referências originais não devem ser copiadas literalmente.
