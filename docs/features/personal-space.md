# Feature — Espaço pessoal

## Objetivo

Comunicar `Preciso ficar sozinha` de maneira respeitosa, sem transformar isso em um pedido que exige ação imediata.

## Para Lidianne

- ação clara para ativar;
- confirmação discreta;
- possibilidade de encerrar quando quiser.

## Para Vinícius

- mensagem calma indicando que Lidianne quer um tempo sozinha;
- esconder/reduzir sugestões insistentes;
- opcionalmente oferecer `Mandar carinho e deixar espaço`.

## Protótipo

Não haverá expiração automática. O estado permanece até Lidianne mudar explicitamente. Notificação de encerramento fica para uma fase com sincronização remota.
